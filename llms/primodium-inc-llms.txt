# Primodium Inc.

> Primodium (primodiumxyz) is a developer-focused studio building fully on-chain applications and games on Ethereum and Solana. It ships two on-chain games and a suite of open-source developer libraries and infrastructure — reactive MUD tables, a Solana DEX indexer with a GraphQL API, a tRPC transaction-sponsoring server, an off-chain MUD indexer, and gasless-transaction relayers.

## Products
- Primodium — a fully on-chain, space-based factory-building game (MUD + Phaser).
- Primodium: Empires — a fully on-chain, turn-based prediction-market game (MUD + Phaser).

## Developer libraries (open source, MIT)
- Reactive Tables — strictly-typed reactive tables for MUD apps (node + browser): https://developer.primodium.com/reactive-tables
- DEX Indexer Stack — Solana DEX trade/token indexer exposing a GraphQL API over Hasura/Timescale: https://developer.primodium.com/dex-indexer
- DEX Server — tRPC server providing protected endpoints for building and sponsoring Solana transactions: https://github.com/primodiumxyz/dex-server
